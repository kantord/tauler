# Self-hosted web fonts

Latin subsets, downloaded from Google Fonts (fonts.gstatic.com) and committed
here so the site makes no runtime requests to a third party.

| File | Family | Source project | License |
|---|---|---|---|
| `dm-mono-400-latin.woff2`, `dm-mono-500-latin.woff2` | DM Mono | https://github.com/googlefonts/dm-mono | OFL 1.1 (`OFL-dm-mono.txt`) |
| `martian-mono-latin.woff2` (variable, wght 400–800) | Martian Mono | https://github.com/evilmartians/mono | OFL 1.1 (`OFL-martian-mono.txt`) |

The SIL Open Font License permits self-hosting, subsetting, and bundling with
software; the license texts must stay next to the font files when they are
redistributed, which is what this directory does.
