:::danger[Extremely early development]
`taulerbox` is at an extremely early stage and basically does not work yet. Do not use it
for anything real. Nothing about it is stable, and it may change or be removed.
:::

`taulerbox` is meant to show a layout's Panels in one window, next to a sandboxed desktop,
instead of drawing each Panel as its own desktop window. It is a separate program, not part
of the `tauler` binary, and sandboxing is a `taulerbox` feature only: native Tauler has none.

The work is tracked in [issue #582](https://github.com/kantord/tauler/issues/582). This page
has no usage instructions, because there is nothing dependable to instruct yet. It will
gain them when the program works.
