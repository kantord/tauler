# tauler-i3

An i3 and sway workspace data source for the [tauler](https://crates.io/crates/tauler)
status bar. It reports the workspaces of an output as JSON, switches workspaces on request,
and can tell i3 how much space the panels occupy.

## Install

```sh
cargo install tauler-i3
```
